# OLYMPUS ENGINE

I'm producing this engine as I feel like there are several engines out there that are bloated and have extra features that aren't needed and simply overriden.
I hope this engine fills that niche.

Plus I live c++ and unless using unreal engine, c++ isn't really used (ignore godot T-T).

I hope to produce something that I can use in a little game jam in the future, setting this a goal will really help me strive a vaiable purpoes for this project. 

OFC I'm very new to the rendering pipeline this will go through several refactors, but I will take as slow as needed and thing about the architecture first before implementing anything to make it as cohesive and simple for others.

## GOAL:

I want to strive for simplcity - while having complexity underneath. 



## Reminder to myself

- In greek mythology olympus was essentially impossible to climb. that of course with time turns out to be false. I want to remind myself that this goal is not as impossible as it seems, and with type education and learning it will be acheiveable. 
- The other reason is the purpose of this simplicity with complexity underneath, IMO greek mythology has a very simple outline of what it is, a fairytale like narative.
